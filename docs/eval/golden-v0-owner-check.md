# 골든셋 v0 주인 확인 목록 (11문항, 약 10분)

**이 목록만 보면 된다. 나머지는 에이전트가 원문과 대조했다.** 50문항 전체의 판정과 방법·한계는 `docs/eval/golden-v0-audit.md`에 있다(문제 없음 44, 수정 0, 애매함 6). 그 대조는 사람 검수가 아니라 골든셋을 만든 것과 같은 종류의 모델이 한 것이라, 여기 11문항은 사람이 직접 본다.

- **1부, 애매함 6문항:** 정답이 틀린 것은 아니고 판단이 갈린다. A/B 중 하나를 고른다. 중요도순이다.
- **2부, 무작위 5문항:** 에이전트가 "문제 없음"으로 판정한 44문항에서 뽑았다. 대조가 믿을 만한지 보는 표본이다.

## 보는 방법

1. 문항마다 **질문 → 정답 → 근거 → 원문 발췌** 순서로 읽는다. 원문 파일을 열 필요는 없다. `>` 인용 블록 안은 2026-11-09에 받은 원문과 저장소 가상 문서의 글자 그대로이고, `…`는 생략한 곳이다.
2. 1부는 A/B 중 하나에 체크한다. 2부는 기존 검수표(`golden-v0-review-sheet.md`)와 같은 세 칸이다.
   - **정답 맞음**: 정답이 발췌와 맞고 빠진 조건(기간·금액·예외)이 없다.
   - **근거 맞음**: `doc_id`와 조항 라벨이 발췌의 조문 머리와 같다. 상품설명서는 `doc_id`만 단다.
   - **질문이 자연스러움**: 고객이나 상담원이 실제로 할 법한 말이다.
3. 걸리는 점은 `메모`에 한 줄로 적는다.

**고른 뒤에는:** B를 고른 문항은 평가 담당이 `golden.jsonl`을 고치고 검증·평가를 다시 돌린다. 2부에서 틀린 것이 1문항이라도 나오면 같은 유형의 나머지 문항을 다시 대조한다.
