- **지원 자격은 대부분 열려 있음** [확인]: LG CNS AI, 롯데이노베이트 AI 서비스·Platform, 현대오토에버 AI 플랫폼·Data, CJ AI 엔지니어, HD현대 일반 AI/AX, 두산 AI.
- **석사↑는 연구형·모델 개발형만** [확인]: 포스코DX AI, HD 조선해양 연구직, LG유플러스 AI.
- **학사 진입 직무명** [추정]: "AI 서비스 엔지니어", "AI Platform/MLOps", "Service Engineer(AI 플랫폼)", "Data Engineer", 사업부형 "AI/AX 엔지니어", "DX/SW 엔지니어" → 공통점은 **모델 연구가 아니라 LLM 응용·서비스·플랫폼 구축/운영**.
- **우회 경로** [확인]: **SKALA**(학력무관, 수료 후 SK AX 채용 연계), Samsung Convergence SW Academy. 삼성SDS는 '소프트웨어' 직군 입사 후 AI 조직 배치 구조 [추정].

## 3. 공통으로 보는 것 Top 5

1. **코딩 구현력** — 삼성SDS SW역량테스트, 현대오토에버·KT DS·롯데 코테, LG CNS 코딩형 검사
2. **생성형 AI 활용 역량 전형 (2026년 급증)** — LG CNS 특화검사, CJ 바이브코딩, HD·포스코 AI활용역량검사, KT AX평가, SK AI역량면접 → **AI 결과물을 검증·재구성하는 능력**
3. **LLM 응용 스택** — RAG, Agent, Vector DB, LangChain/LangGraph, vLLM, FastAPI
4. **배포·운영** — Docker/K8s, CI/CD, AWS/Azure, MLOps
5. **고객 산업 도메인 문제해결** — 금융·공공·제조·물류. 영어 회화 성적은 기본 조건(삼성SDS·포스코·HD)

## 4. 포트폴리오 반영 포인트

- 고객 산업 문서 + 엔터프라이즈 시나리오 (금융 약관, 제조 매뉴얼, 사내 규정 QA)
- 청킹·하이브리드·리랭커 + 자체 평가셋 Recall@k/Faithfulness, 개선 전후 표
- LangGraph 도구 호출 + **MCP 서버 1개** (롯데·현대오토에버 키워드)
- FastAPI + Docker + 클라우드 + GitHub Actions, 지연·비용 로그, **온프레미스 SLM(vLLM) 옵션**
- 출처 인용, 권한별 문서 접근, PII 마스킹, 근거 없으면 거절
- **AI 코딩 도구 사용과 검증 과정 기록** (바이브코딩·AI활용 평가 대비)
- **고객 PoC 형식 문서**: 문제정의 → 요구사항 → 아키텍처 → 성과·한계
