## 3. 빅테크 서류 통과용 RAG 포트폴리오 수준 [추정, 근거는 공고]

1. "LangChain + 벡터DB 챗봇"은 **최소선**. 청킹·임베딩·하이브리드·리랭커 **ablation 표** 필요 (Recall@k, MRR, faithfulness, judge-사람 일치도).
2. **직접 라벨링한 골든셋 200~500문항 공개**, 실패 유형 분류, CI 회귀 테스트.
3. 운영 경험 대체: Locust 부하테스트로 **p95 지연·처리량·토큰 비용**, vLLM 서빙 + 캐싱 개선율, Langfuse 대시보드, 실사용자 수십 명 피드백 기록.
4. 오픈소스: LangChain·LlamaIndex·vLLM·RAGAS 등 **머지된 PR 1~3건**(문서 수정 말고 버그 수정·기능), 또는 Kaggle/LLM 대회 상위권.
5. 도메인 문제: 일반 PDF 챗봇보다 의료·법률·사내문서 같은 **실제 문제 + 에이전트형 검색 + 근거 검증**.
