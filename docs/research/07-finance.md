## 2. 학사 신입이 금융권 AI 직무로 들어가는 경로

1. **은행 IT·디지털 공채 → AI 부서 배치 (주 경로)** — 학사가 막힌 곳 없음. 신입 AI 직무명은 KB AI·플랫폼개발, 신한 AI 애플리케이션 엔지니어링, 하나 AI/데이터 금융, 한화 AI/데이터. **첫 관문은 알고리즘 + SQL 코딩테스트.**
2. **채용연계형·체험형 인턴** — 케이뱅크(AI 과제 → 전환), KB 하계 체험형 인턴 AI·플랫폼개발, 토스뱅크 서버 인턴.
3. **IT 자회사** — 하나금융TI, 신한DS, 농협정보시스템 학사 가능. 단 AI 연구직은 박사 → 학사는 AI 애플리케이션·플랫폼 개발로.
4. **핀테크는 백엔드로 먼저** — 토스·카카오 테크 직군 학력무관이지만 ML/LLM 직무는 K8s·Spark 실무 요구 → 서버로 입사 후 AI 팀 이동 [추정].
5. **교육·대회 → 서류 우대** — KB **SSAFY 우대**, 우리FISA 수료자 계열사 우대, 한화 Future Talent Contest 서류 면제, 토스 NEXT ML 챌린지 본선 서류 면제(2025).
6. **자격증 우선순위** [추정] — 정보처리기사 + SQLD(→SQLP) + ADsP 기본 세트.

## 3. 금융권에서 RAG 포트폴리오가 강점이 되려면 Top 5

1. **폐쇄망·망분리 모드** — 외부 API 없이 로컬 LLM·임베딩·벡터DB로 동작, 오프라인 설치 가능. '내부망 전용 / 클라우드 허용' 설정 전환. (2026-04 SaaS 망분리 예외 시행, 단 대체 통제 의무)
2. **개인(신용)정보 마스킹** — 수집·로그 단계에서 주민번호·계좌·카드번호 탐지·마스킹, 프롬프트 인젝션·유출 테스트. (KB IT 직무에 '개인(신용)정보보호 관리시스템' 명시)
3. **근거 인용·환각 통제를 수치로** — 조항·페이지 인용, 근거 없으면 거절, recall@k·faithfulness·정답률, 회귀 테스트.
4. **권한과 감사** — 부서·직급별 ACL 검색 필터, 질의·응답 감사 로그, **Human-in-the-loop + 긴급 정지** (2026-06 금융분야 AI 가이드라인 개정안 '보조수단성 원칙')
5. **규제·내규 문서 시나리오** — 약관·상품설명서·전자금융감독규정 같은 조항·표 문서 파싱 + 개정 버전 관리, '상담 챗봇' 또는 '내규 Q&A' (KB "챗봇·콜봇·AI Agent", "행내 데이터 커스터마이징"과 직결)

**전제**: 은행 대부분은 **코테(알고리즘·SQL)가 먼저**, 포트폴리오는 그다음 (신한 필수 제출, KB는 코테 합격자만 제출 [2차]). 포트폴리오만으로는 부족 → 코테 병행.
